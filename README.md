# DowntimeOps — Enterprise Downtime Scheduler

DowntimeOps is a web-based tool for scheduling, tracking, and auditing application downtime events across enterprise systems. It provides a unified dashboard for IT teams to manage planned and unplanned outages, ensuring transparency and coordination across business units.

## Features

- Central dashboard for active, scheduled, completed, and cancelled downtimes
- Role-based access: master users and application-specific users
- Schedule new downtime windows with detailed messages
- Filter and search downtime records by application, status, and date
- Audit trail of all actions performed in the session
- Responsive, modern UI for desktop and tablet

## Usage

1. Open `downtime-manager.html` in a modern web browser.
2. Select your user role to start a session.
3. View dashboards, schedule new downtimes, or review audit logs.

## Project Structure

- `downtime-manager.html` — Main application UI and logic
- `scripts/` — (Reserved for automation or backend scripts)

## Requirements

No server or backend required. All logic runs in the browser. For production, integrate with your backend as needed.
